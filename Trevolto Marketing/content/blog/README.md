## Where to publish (free; aim for dofollow)
**Crypto-niche (best fit, usually dofollow):** Publish0x · Hive/PeakD · Steemit · Read.cash · Minds
**Your-own-blog (you control → dofollow):** Blogger/Blogspot · GitHub Pages · Hashnode · Tumblr · Write.as
**High traffic (often nofollow, still worth it):** Medium · Dev.to

## Step-by-step
1. **Pick ONE primary home** for each post (e.g. your Hashnode or Blogger). Publish the full post there first.
2. **Syndicate** to the other platforms. On each, add a line at the top or bottom:
   *"Originally published at <primary-URL>"* and, where possible, set the **canonical URL** to the primary. This avoids duplicate-content penalties while still earning links.
3. **Vary the anchor text** across sites — e.g. "Trevolto", "automated crypto trading app", "crypto trading bot for Windows & macOS". Don't use the exact same anchor every time.
4. **Add 1 relevant image** per post (reuse a cover/mockup from `../../covers/` or `../../mockups/`).
5. **Verify dofollow:** right-click your link → Inspect → check for `rel="nofollow"`, or use the free "NoFollow" / "SEO Minion" Chrome extension.
6. **Don't mass-blast.** Publish 1–2 per week, naturally. Quality + relevance > volume.

## Compliance (keep on every post)
- Keep the disclaimer at the bottom ("not financial advice · capital at risk").
- No profit guarantees; any figures must be labelled *illustrative*.
- Respect each platform's rules on financial/crypto content.

## Note on auto-publishing
These can't be auto-posted from here — each platform needs your own login. Copy
the markdown in; most of these platforms accept Markdown directly.
