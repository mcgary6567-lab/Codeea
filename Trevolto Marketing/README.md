# Trevolto Marketing

All Trevolto brand & marketing assets, organized by purpose. Everything here is
generated from scripts in `../trevolto/` (re-runnable) — see "Generated by" below.

```
Trevolto Marketing/
├── brand/        Brand guidelines (visual one-pager + doc)
├── logos/
│   └── avatars/  Profile pictures (chevron + TREVOLTO) — WhatsApp / Facebook / TikTok + master
├── covers/       Platform covers & banners (Facebook, X, LinkedIn, YouTube, Discord) + 16:9 cover
├── hero/         Website hero (transparent, full-white text) — 1920 / 1280 / 960
├── mockups/      macOS-framed app mockups
├── previews/     "How it looks" montages (e.g. Facebook page header)
├── content/      Written content packs (Facebook, Instagram, TikTok, WhatsApp)
└── creatives/    The 70-piece social set
    ├── posts/    square · vertical · instagram · linkedin
    └── reels/    organic (main-window/strategy-chart/backtest/analytics) · ads-safe (images+video)
```

## What's where

| Folder | Contents | Generated by |
|---|---|---|
| `brand/` | `brand-guidelines.png`, `brand-guidelines.md` | `trevolto/make_brandsheet.py` |
| `logos/avatars/` | `profile-{whatsapp,facebook,tiktok}-*.png`, `avatar-master-1024.png` | `trevolto/make_social.py` |
| `covers/` | `facebook-cover.png`, `banner-*.png`, `cover-1920x1080.png` | `make_social.py`, `make_cover.py --fb` |
| `hero/` | `website-hero.png` (+ `-1280`, `-960`) | `trevolto/make_cover.py` |
| `mockups/` | `macos_main.png`, `macos_chart.png` | `trevolto/make_macmockup.py` |
| `previews/` | `facebook-page-preview.png` | one-off montage |
| `content/` | `facebook.md`, `instagram.md`, `tiktok.md`, `whatsapp.md` | hand-written |
| `creatives/` | 70 posts + reels | `trevolto/make_reel.py` |

## Brand quick-reference
- **Primary:** teal `#2dd4bf` · **secondary:** smoke gray `#1b1f24` / `#23282e`
- **Accents:** cyan `#22d3ee`, light green `#4ade80` · **mark gradient:** teal→blue→violet
- Full rules in `brand/brand-guidelines.md`.

## Compliance
Promo copy uses **illustrative** figures only, carries a risk line ("Crypto trading
carries risk — you can lose money. Not financial advice."), and never promises profit.
Paid ads should use the `creatives/reels/ads-safe/` clips.

> The core logo source files live in `../trevolto/` (`logo.png`, `trevolto_logo.png`,
> `favicon.png`) and the website logo in `../site-trevolto/assets/img-01.png`.
