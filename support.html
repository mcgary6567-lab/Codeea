Common Issues

🔧 EA not placing any trades?

Most likely causes:

  1. Algo Trading is off — the toolbar button must be green and Allow Algorithmic Trading ticked in the EA dialog
  2. The licence URL isn't whitelisted under Tools → Options → Expert Advisors, or your account isn't authorised
  3. It's outside the allowed sessions, or a news / spread filter is pausing entries
  4. There simply isn't a valid EMA-cross signal yet

The Experts and Journal tabs always log the reason. Full guide: Telegram Setup Guide

📩 Telegram alerts not arriving?

Set use_telegram=true with the correct bot token and chat ID, and allow https://api.telegram.org under Tools → Options → Expert Advisors. On attach the EA sends a "connected" test message — if it doesn't arrive, the Experts tab shows the exact error code.
