# Social media kit

Promo creatives for the Prometheus AI Crypto Bot. Generated by
`trading_bot/make_reel.py` (images + MP4) + `trading_bot/make_mockup.py`
(the app windows embedded in them). Re-run `python make_reel.py` to rebuild
everything into the folders below. **Filenames are auto-derived from each
creative's hook**, so you can tell them apart at a glance.

```
social/
├── AD_COPY.md                     Ad text, headlines, voiceover + compliance notes
│
├── paid-ads-safe/                 ✅ USE FOR PAID TikTok / Meta ADS
│   ├── images/   NN-<hook>.png    feature-led · NO profit claims · demo (Safe Mode) UI
│   └── video/    NN-<hook>.mp4    1080×1920 · 6s · TikTok/IG safe-zone · features animate in
│
└── organic/                       ⚠️ ORGANIC POSTS ONLY (profit-led — don't boost)
    ├── main-window/    NN-<hook>.png   reels showing the main dashboard (BUY/SELL, positions)
    ├── strategy-chart/ NN-<hook>.png   reels showing the candle chart + BUY/SELL signals
    ├── backtest/       NN-<hook>.png   reels showing backtest stats + equity curve
    ├── analytics/      NN-<hook>.png   reels showing the performance dashboard
    ├── posters/        tiktok-hero.png · facebook-hero.png · square-post.png
    └── video/          profit-reel.mp4 (1080×1920 · 5s · profit ticker)
```

All vertical creatives are **1080×1920 (9:16)** Full-HD (work for TikTok, FB/IG
Reels, and FB feed posts); `square-post.png` is **1080×1080** for the feed.

## Which set to use
- **Paid ads (TikTok/Meta):** `paid-ads-safe/` only — no "$ per trade" / profit
  figures, demo visuals, risk disclaimer. Pair with copy in **`AD_COPY.md`**.
- **Organic posts:** `organic/` — punchier profit-led creatives, grouped by the
  app window they show. Do **not** put paid spend behind these (financial-ad
  policy risk — see AD_COPY.md).

## Identifying a creative
The **folder** tells you the app window; the **filename** tells you the hook —
e.g. `organic/strategy-chart/03-up-or-down-it-profits.png`. Hooks use varied
accent/font colours so a grid reads as a set, not duplicates.
