# Social media kit

Promo creatives for the Prometheus AI Crypto Bot. Generated by
`trading_bot/make_reel.py` (images + MP4) and `trading_bot/make_mockup.py`
(the app screenshots embedded in them). Re-run `python make_reel.py` to rebuild
everything into the folders below.

```
social/
├── AD_COPY.md                  Ad text, headlines, voiceover + compliance notes
├── paid-ads-safe/              ✅ use for PAID TikTok/Meta ads
│   ├── images/  reel_safe_01–08.png      feature-led, NO profit claims, demo UI
│   └── video/   reel_safe_01–08.mp4      1080×1920 · 6s · TikTok/IG safe-zone
└── organic/                    ⚠️ organic posts only (profit-led — don't boost)
    ├── images/  reel_01–30.png, tiktok_reel.png, facebook_reel.png, square_post.png
    └── video/   reel.mp4                 1080×1920 · 5s · profit ticker
```

## Which to use
- **Paid ads (TikTok/Meta):** `paid-ads-safe/` only — no "$ per trade" / profit
  figures, demo (Safe Mode) visuals, risk disclaimer. Pair with copy in `AD_COPY.md`.
- **Organic posts:** `organic/` — punchier profit-led creatives. Do **not** put
  paid spend behind these (financial-ad policy risk).

All vertical creatives are **1080×1920 (9:16)**; `square_post.png` is **1080×1080**.

See **AD_COPY.md** for the crypto-ad eligibility warnings before spending.
