# Social media kit

Promo creatives for the Prometheus AI Crypto Bot, organised **by purpose**.
Generated by `trading_bot/make_reel.py` (+ `make_mockup.py` for the app windows).
Re-run `python make_reel.py` to rebuild everything into the folders below.
**Filenames are auto-derived from each creative's hook** for easy identification.

```
social/
├── AD_COPY.md                       Ad text, headlines, voiceover + compliance notes
│
├── reels/                           Vertical 9:16 — TikTok · Facebook Reels · Instagram Reels
│   ├── ads-safe/                    ✅ USE FOR PAID ADS (no profit claims, demo UI)
│   │   ├── video/   NN-<hook>.mp4   1080×1920 · 6s · safe-zone · features animate in
│   │   └── images/  NN-<hook>.png   reel covers / static reels
│   └── organic/                     ⚠️ organic only — profit-led (don't boost)
│       ├── video/          profit-reel.mp4   (1080×1920 · 5s · profit ticker)
│       ├── main-window/    NN-<hook>.png      main dashboard (BUY/SELL, positions)
│       ├── strategy-chart/ NN-<hook>.png      candle chart + BUY/SELL signals
│       ├── backtest/       NN-<hook>.png      backtest stats + equity curve
│       └── analytics/      NN-<hook>.png      performance dashboard
│
└── posts/                           Feed posts
    ├── square/     square-post.png    1080×1080 — Facebook / Instagram feed
    ├── vertical/   tiktok-hero.png · facebook-hero.png   1080×1920 image posts
    ├── instagram/  NN-<hook>.png      1080×1350 — Instagram feed (portrait, profit-led)
    └── linkedin/   NN-<hook>.png      1200×1200 — LinkedIn feed (square, professional tone)
```

## Where each goes
| You want to post… | Use |
|---|---|
| **TikTok / FB Reel / IG Reel (video)** | `reels/ads-safe/video/` (paid) · `reels/organic/video/` (organic) |
| **Reel cover / static vertical** | `reels/*/images/` or `reels/organic/<window>/` |
| **Facebook / Instagram feed (square)** | `posts/square/` |
| **Facebook / IG portrait image post** | `posts/vertical/` |
| **Instagram feed (portrait 4:5)** | `posts/instagram/` (10 profit-led, varied colours) |
| **LinkedIn feed (square)** | `posts/linkedin/` (10 professional, backtest-framed) |

## Paid vs organic
- **Paid ads (TikTok/Meta):** use **`reels/ads-safe/`** only — feature-led, no "$
  per trade" / profit figures, demo visuals, risk disclaimer. Copy: **`AD_COPY.md`**.
- **Organic:** `reels/organic/` + `posts/` — punchier, profit-led. Don't put paid
  spend behind these (financial-ad policy risk — see AD_COPY.md).

The **folder** tells you the app window; the **filename** tells you the hook
(e.g. `reels/organic/strategy-chart/07-up-or-down-it-profits.png`).
