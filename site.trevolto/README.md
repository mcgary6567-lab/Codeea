# trevolto.com — marketing website

Drop the current trevolto.com website files into this folder (index.html,
css/, js/, images/, assets/, etc.). Keep the same structure the live site
uses so links keep working.

Once the files are committed and pushed, Claude can edit them here.

- App (the SaaS dashboard) lives in `app.trevolto/` and is deployed separately
  to Fly.io (trevolto-bot). This folder is ONLY the public marketing site.
- The app links to: https://trevolto.com/checkout, https://trevolto.com/contact,
  and the logo https://trevolto.com/assets/img-01.png — keep those paths valid.
