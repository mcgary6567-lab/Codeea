No disciplinary action rests on an AI score alone.

An AI class score, churn risk or complaint classification is an input to a human judgement, never the judgement itself. Before any warning, grade change, salary consequence or termination: a person reviews the recording or the record, the teacher or employee is heard, and the decision is written in the decision register with its own rationale. AI output that falls below the module threshold below must be reviewed before it is used at all.

{% call ui.card('How thresholds are used') %}
  • An output below its module threshold is flagged in the run log and pushed up the review queue.
  • Class monitoring and complaint classification always queue for human review, whatever the confidence.
  • A rising false-positive rate is the signal to retune the prompt, not to lower the threshold.
  • Every review — approve, reject, override, false positive — is written to the audit trail with its reason.
{% endcall %} {% call ui.card('Data handling') %}

Payloads sent to the gateway are summarised and stored with each run so an output can always be reproduced and explained. On this deployment the provider is simulated unless an API key is configured, which means no student or family data leaves the server. Check the current provider on the model registry.
