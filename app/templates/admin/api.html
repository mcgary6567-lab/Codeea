{% call ui.card("Using a key") %}

Send the raw key in the X-API-Key header on any /api/v1 request:

curl -H "X-API-Key: oqc_live_xxxxxxxx" \
     {{ base_url }}/api/v1/auth/me

Interactive sessions use a bearer token instead — POST /api/v1/auth/login returns one.

{% endcall %} {% call ui.card("Key handling rules") %}
  • Only a SHA-256 hash is stored. The raw key is displayed once, at creation, and can never be recovered.
  • A key inherits its owner's permissions; scopes narrow that down but never widen it.
  • Give every integration its own key so one can be revoked without breaking the rest.
  • Revocation is immediate and is logged as a critical audit event.
